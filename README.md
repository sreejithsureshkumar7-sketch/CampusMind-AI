# CampusMind AI Level 2-6 Upgrade

Features:
- Firebase Authentication login
- Firestore cloud save
- Add/Edit/Delete/Search students
- AI risk prediction
- Placement readiness score
- AI chatbot
- PDF report download
- JSON export
- Responsive dashboard

Setup:
1. Replace firebase-config.js with your Firebase web config.
2. Enable Firebase Authentication Email/Password.
3. Enable Firestore Database.
4. Add Firestore rules from firestore-rules-demo.txt.
5. Upload all files to GitHub root and enable GitHub Pages.
